# 实验二 高频功率放大器 - 预习报告

## 一、 实验目的与要求

1. 深入理解丙类（C类）功率放大器的基本工作原理，掌握其大信号输入且高转换效率（通角 $\theta < 90^\circ$）的工作机制。
2. 熟练掌握影响高频功率放大器工作状态（欠压、临界、过压）的三大核心因素：**输入激励电压、集电极供电电压以及集电极等效负载阻抗**。
3. 学会使用高频信号源和示波器来捕捉和分析丙类放大器在不同状态下的典型的电流脉冲波形（特别是过压时的马鞍形）。
4. 通过实验了解并验证振幅调制（AM）在高频功率放大器中是如何随基带信号变化而产生包络的。
5. 了解如何测试调谐放大器的幅频响应并估算终端实际交流输出功率。

## 二、 实验核心原理简述

高频功率放大器主要作用是在发射机的末端向天线提供足够的高频输出功率。为了获得高效率，该电路一般被偏置在截止区域，即**丙类状态**。只有当基极高频激励信号大于一定的导通门限时，晶体管才会在少于半个周期（通角 $\theta < 90^\circ$）内导通，产生**脉冲断续的集电极电流**。

然而射频信号是以平滑正弦波发送的，这便需要接在集电极的 **LC 并联谐振回路** 发挥“飞轮”与“滤波”双重作用。LC 回路的阻抗仅在谐振频率（基波）处表现为最大纯阻，从而提取出基带高压正弦信号，而将各种谐波短路滤除。

由于静态与动态参数的交织，在给定供电和激励的情况下，晶体管随着管压降（$U_{ce}$）和饱和压降的博弈，会呈现三种状态：
- **欠压状态**：恒流特性明显，输出功率尚未最大，脉冲呈余弦段。
- **临界状态**：输出功率和效率均达到最高点的折中边缘。
- **过压状态**：管压降触底，晶体管在脉冲核心区域进入饱和，引起脉冲顶部塌陷（马鞍形），波形严重非线性。

## 三、 实验仪器与接线规划

1. **实验教学平台（RZ9653型）**：高频原理模块 -> 非线性丙类功率放大模块。
2. **高频信号源**：用于产生 2.1MHz 和 6.3MHz 的射频激励信号。
3. **两通道数字示波器**：观察输入激励、LC回路电压和集电极脉冲波形。
4. **数字万用表**：用于监测调节过程中的静态偏置电压（如 4V）和集电极回路阻抗（如 4k$\Omega$）。

## 四、 实验操作流程与预估结果

### 1. 前置级甲类放大的验证 (6.3MHz)
- **流程**：将 400mV 左右的 6.3MHz 考查信号接至 3P2，观测初级增益网络前后的电压（3TP2 输入，3TP3 输出）。
- **预估现象**：因无选频槽路，放大倍数固定，输出应随波形严格线性呈现，不失真拉高。

### 2. 三参数（激励幅度/供电电压/负载电阻）对丙态的干预测试 (2.1MHz)
- **参数控制法**：打下开关 3K1 至右路以启用低频 2.1MHz 槽路便于记录。
- **流程 A（变激励）**：定 $E_c=4\text{V}$, $R_L=4\text{k}\Omega$，渐进微小增大示波器监测源。
  - *预估事实*：初始波形显窄余弦帽；当激励持续加强，顶峰下沉反弹分裂成对称双尖马鞍形。
- **流程 B（变电压）**：恢复激励至临界，旋扭 3W3 下调 $E_c$ 大小（即从 7V 减到 3V）。
  - *预估事实*：降低集电极压差会极度压缩晶体管的放大活动空间，使得波形极速坠入深深的过压塌陷坑（更剧烈的马鞍形）。
- **流程 C（变负荷）**：通过 3W4 旋扭调节 $R_L$。在拨量之前应置开关为 off 以确保万用表单独获取阻值，后合进行路演。
  - *预估事实*：阻抗加大会极大加高交流摆幅引起早衰进入饱和区，增大阻抗直接等效走入过压区。

### 3. 高频频响调谐特性扫频 (6.3MHz网络)
- **流程**：将开关 3K1 划回左端。在中心频段 6.3MHz（幅400mV固定）上，依次向两侧延展以 200kHz 为差量测量 3TP4 读取极值并制表。
- **预估事实**：与小信号类似形成类似钟形的谐振带，仅在 6.3MHz 内阻抗极大，放大倍数顶峰呈现。

### 4. 振幅调制AM与最终输出效能标定
- **流程**：利用 3P1 注入附加低频语音段。接通 3K3 和 3K4。通过 3TP4 看包络线。最终测 3TP8 (承载于100欧姆电阻)。
- **预估事实**：通过射频等幅波的缩放包络可以直观验证 AM 调幅机理。测出的终波转化为有效值利用 $P_o = \frac{U_{rms}^2}{100}$ 公式可验证能量放大效果。

## 五、 注意事项与难点

- **状态捕捉**：从欠压到临界再到过压的过渡边界极为狭窄且伴随高频温漂，可能需要细致且重复的微步长转动旋钮。
- **防干扰问题**：2.1MHz与6.3MHz容易引入空间辐射，示波器地线夹角要短并与探针贴近测量区域。
- **不带电测阻**：切记，用低压万用表接触负载电位调整端进行静态电阻读取时，**严禁带电（通过3K2断开隔离）**，以防损毁仪表或发生短路失效。
