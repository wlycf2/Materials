# Course-materials

## 仓库内容

本仓库集中存储高频电路实验课程资料，主要包括：

- 五个实验项目的实验资料、实验报告、数据、图片和相关脚本：
  - 实验一：小信号调谐放大器
  - 实验二：高频功率放大器
  - 实验三：正弦波振荡器
  - 实验四：振幅调制
  - 实验五：振幅解调器
- `实验报告Latex模板.tex`：实验报告 LaTeX 模板。
- `Google-Drive-Resources.md`：与课程资料相关的四个 Google Drive 文件夹链接汇总。

上述实验资料已统一放置在 [`High-Frequency-Circuit-Experiments`](High-Frequency-Circuit-Experiments/) 目录中。
